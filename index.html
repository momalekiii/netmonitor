Core Architecture & Modules

JA3 Fingerprinting ja3_fingerprinting.py

Profiles TLS client handshakes to detect malware, botnets, and unauthorized scanners over encrypted traffic.

Bandwidth Anomaly bandwidth_anomaly.py

Continuous throughput baseline modeling to catch DDoS spikes and abnormal data exfiltration in real time.

DNS Leak & Tunnel Guard dns_leak.py / tunnel.py

Monitors active VPN and tunnel interfaces to ensure zero recursive DNS leaks or unexpected route drops.

Fail2Ban & Auto-Remediation auto_remediation.py

Self-healing triggers that automatically ban hostile IPs via Fail2Ban and restart degraded network services.

SSL Transparency ssl_transparency.py

Audits TLS certificates and Certificate Transparency logs to prevent spoofing and unexpected expirations.

Multi-Server & Prometheus prometheus.py

Syncs telemetry across remote fleet nodes (`multi_server.py`) and exposes native Prometheus metrics.

Telegram Bot & Webhooks telegram_bot.py

Instant push notifications, scheduled status reports, and outbound webhooks for real-time incident response.

Threat Intel & REST API intel.py / api.py

Cross-references active connections with threat intelligence feeds and provides a clean REST API & CLI.

Quick Deployment

1. Docker Compose
docker compose up -d --build
2. Systemd Daemon
sudo ./install.sh
sudo systemctl enable --now netmonitor
3. Python CLI
pip install -e .
netmonitor --help
